# LittleWhiteBox

面向 SillyTavern 的多功能扩展，为长篇角色扮演提供剧情记忆、状态管理、绘图、语音和应用面板。

## 主要功能

- 剧情总结与记忆：整理剧情，辅助长对话中的记忆召回。
- 变量与任务：管理角色状态、委托和任务进展。
- 绘图与语音：生成剧情插图，播放角色语音。
- 小白 OS：集中使用地图、私人通讯、语言学习、钱包和游戏等应用。

# 二改特色（相较官方 3.1.6）

## NovelAI 生图

### 新增Vibe功能
- 上传 Vibe 参考图，每张可独立启用／停用并调整强度滑杆。
- Vibe 分组保存：勾选多个vibe保存为组。
- 保存当前画师串同时保存当前已保存的vibe状态
- 预设导入／导出自带 Vibe 资料，云端分享的预设亦包含 Vibe。

### 预设管理增强
- 视觉化管理画师串：上传预览图，楼层面板直观快捷切换
- 预设导出／导入与「智绘姬」互通，含模型参数、缩略图与 Vibe。

### 新增图片标题和折叠功能
- 修改插入正文的外观，更省空间
- `overlay`：图顶细悬浮标题条，桌面 hover 显示；触控轻按图片短显 2 秒。
- `collapse`：可折叠标题，点标题折叠／展开图片。
- `none`：不显示标题。

### 跨楼层画面连续性
- **上镜锚点**：系统维护的角色入画账本，记录角色最近一次实际下发给生图模型的英文 tag（外貌、服装）。
- 规划 LLM 须逐字覆用锚点；仅正文明确写出变化（染发、换装、受伤等）才改写，正文与锚点冲突以正文为准。
- **通用角色过滤**：路人、通用称呼（姐姐、老师、NPC、stranger 等中／日／英 30+ 规则）不建档、不记锚点。
- 连续性规则 Pro 提示词集，约束服装版型／颜色／部件的版本传承。

### 快速测试持久化
- 快速测试生成的图逐张存入画廊（不再只活在记忆体）。
- 测试页下方显示历史缩略条，点主图或「打开画廊」进入完整画廊；切页、重生、重开设置均保留（受快取天数设置约束）。
